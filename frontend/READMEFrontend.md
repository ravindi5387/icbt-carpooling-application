# Frontend - ICBT Carpooling Application

## Technology Stack
- React
- TypeScript
- CSS

## Main Features
- User Authentication
- User Dashboard
- Driver Dashboard
- Ride Search
- Ride Creation
- Booking Management
- Trip History
- Notifications
- Profile Management

## Project Structure

- `src/components` - Reusable UI components
- `src/pages` - Application pages
- `src/services` - API/service logic
- `src/context` - Application state/context
- `src/assets` - Frontend assets
